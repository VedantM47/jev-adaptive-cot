## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem (documents_dir) → ingest | Files read and embedded; names become document IDs |
| operator CLI args / YAML → ingest | Paths chosen by the local developer |
| index_dir artifacts → FaissRetriever | On-disk artifacts deserialized at load |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-02 | Tampering / Information Disclosure | discover_documents | medium | mitigate | Non-recursive `*.txt` glob. Symlinks are rejected, as are resolved paths outside the resolved documents_dir. The filename regex blocks separators and dots. Tested in Task 2. |
| T-04-03 | Tampering | FaissRetriever.from_index_dir | medium | mitigate | Missing, mismatched and tampered artifacts raise FileNotFoundError, ValueError or ValidationError. Tested in Task 3. |
| T-04-07 | Information Disclosure / repo hygiene | generated index binaries | low | mitigate | `.gitignore` rule for `data/processed/faiss_index/`, verified with `git check-ignore` |
| T-04-08 | Tampering | CLI path arguments | low | accept | Single-user local research CLI; the operator is trusted. Discovery containment applies after path resolution. |
</threat_model>
