Helpers:
- `_write_corpus(root: Path) -> Path` writes three synthetic docs into `root / "docs"`, each starting with a `# SYNTHETIC` comment line:
  - ACME_10K_FY23.txt: 3 one-line paragraphs about revenue, gross margin, and R&D.
  - ACME_Q4_Earnings_FY23.txt: 2 paragraphs about fourth-quarter revenue and guidance.
  - BETA_10K_FY23.txt: 2 paragraphs.
- `_InMemoryKeywordBackend(RetrievalBackend)` stores `tuple(chunks)` and implements ONLY `_search`. It filters by company, period and optional document_type. Its score is the Jaccard overlap of lowercase word sets of query and chunk text, in [0, 1]. It sorts by `(-score, chunk_id)` and returns the first top_k as `RetrievedChunk.model_validate({**c.model_dump(), "score": s})`.
- A parametrized fixture `backend` with params ["faiss", "in_memory"]:
  - "faiss" pulls `request.getfixturevalue("embedder")`, runs build_index over the corpus into tmp_path using RetrievalConfig() chunk settings, and returns `FaissRetriever.from_index_dir(...)`.
  - "in_memory" builds from `load_chunks(corpus, max_words=..., overlap_words=...)` and never touches the embedder.
- `_collect_evidence(backend: RetrievalBackend, **kwargs) -> RetrievalResult` is the consumer. It uses only the base API, which demonstrates that callers need no backend-specific code.
- Log capture: a fixture adding a callable loguru sink for component=="retrieval" records, removed by id in teardown. A second fixture restores global loguru handlers after setup_logging.

Tests:
- `test_base_class_is_abstract`: `RetrievalBackend()` raises TypeError.
- `test_subclass_without_search_is_not_instantiable`: a subclass defining nothing raises TypeError on instantiation.
- `test_swap_backends_share_contract(backend)`:
  - Query company ACME, period FY2023, a revenue query, top_k 10.
  - Assert: the result is a RetrievalResult; 1 ≤ len(chunks) ≤ 10; every chunk is ACME/FY2023; every `source_tier == SOURCE_TIER_BY_DOCUMENT_TYPE[document_type]`; both SourceTier values appear (ACME has a 10-K and an earnings release); scores are non-increasing; `result.backend == type(backend).__name__`; `result.latency_ms >= 0` and `result.latency_seconds == result.latency_ms / 1000`.
- `test_document_type_filter_applies_to_every_backend(backend)`: EARNINGS_RELEASE returns only SECONDARY chunks from ACME_Q4_Earnings_FY23; TEN_K returns only PRIMARY chunks.
- `test_each_call_emits_one_latency_record(backend)`:
  - Make two calls; assert exactly two captured records.
  - Each record's extra has component "retrieval", backend equal to the class name, a float latency_ms ≥ 0, and num_results equal to len(chunks) of the matching call.
- `test_latency_written_to_run_jsonl(tmp_path, restore_logging)`:
  - Call `setup_logging(log_dir=tmp_path / "logs", run_id="retrieval-latency")`, then one retrieve on the in-memory backend, then `logger.remove()` to flush and close the sinks.
  - Parse `retrieval-latency.log.jsonl` and assert a line whose record.extra.component is "retrieval" has latency_ms == round(result.latency_ms, 3).
- Contract-violation tests use tiny rogue `_search` backends: one returns a chunk for another company, one returns another document_type while a filter is set, one returns unsorted scores, one returns top_k + 1 chunks. Each raises RetrievalContractError on retrieve().

Tests are not in mypy's scope, but keep full type hints and a docstring on every test. Use `# type: ignore[abstract]` where instantiating abstract classes. Change src/jev_cot/retrieval/base.py only to fix a genuine defect a test exposes.
