<objective>
Tracer: one real end-to-end retrieval slice through every layer the phase touches. The slice runs from the seed document file, through ingest (read, chunk, tag, embed, write the FAISS index plus sidecar plus manifest), then the FAISS backend (load, search, join metadata), then the abstract interface (validate, time, log, typed result), and ends at a pytest end-to-end check.

Purpose: Prove the architecture (ABC + swappable backend + sidecar metadata + latency instrumentation) on one path before the Wave 3 expansions (swap/contract tests 04-03, full seed corpus 04-04, ingest CLI + hardening 04-05). This slice is production-quality: all expansion plans build on these exact signatures.

Planner decisions (Claude's discretion per 04-CONTEXT.md):
- Package location: `src/jev_cot/retrieval/` (import path `jev_cot.retrieval.*`), NOT the top-level `retrieval/` placeholder. This follows the Phase 2/3 precedent, where the ROADMAP paths `controller/actions.py` and `data/schema.py` were implemented as `src/jev_cot/controller/actions.py` and `src/jev_cot/data/schema.py`. It is also the only location covered by CI's `mypy src/`, the wheel build (`packages = ["src/jev_cot"]`) and `--cov=jev_cot`. Leave the top-level `retrieval/__init__.py` placeholder untouched, the same way Phase 2 left top-level `controller/`.
- Index: `faiss.IndexFlatL2` (exact search, no training) over L2-normalized embeddings. For unit vectors, squared L2 distance d gives cosine similarity as 1 - d/2. That conversion yields a bounded, higher-is-better score (research Pitfall 4) while keeping the IndexFlatL2 choice. FAISS id i equals line i of the chunks.jsonl sidecar.
- Template method: `RetrievalBackend.retrieve()` is concrete and `@final`. It validates input, times the abstract `_search()`, enforces the result contract, logs latency and returns a `RetrievalResult`. A new backend implements only `_search()` and inherits validation, latency logging and contract checks. That is what the ROADMAP swap-test criterion asks for.
- Latency: `RetrievalResult.latency_ms` (plus the `latency_seconds` property, the unit of Appendix B `latency_breakdown["retrieval"]`) is returned to the caller for the future trajectory logger. It is also logged per call with `component="retrieval"`. Ingest time is logged separately with `component="ingest"` (research Pitfall 5). Model-load time never enters per-call latency.
- Seed document format: UTF-8 `.txt` named `{DOCUMENT_ID}.txt`. Lines whose first non-space character is `#` are comments and are not indexed (this keeps the synthetic disclaimer out of retrieval results). Each paragraph sits on one line, with a blank line between paragraphs.

2. src/jev_cot/retrieval/base.py — the swappable interface (FR-11). Implement exactly the base.py contract in <interfaces>:
- `SourceTier` and `DocumentType` are StrEnums, following the QuestionType/Action convention.
- `SOURCE_TIER_BY_DOCUMENT_TYPE` is a `types.MappingProxyType`: TEN_K→PRIMARY, TEN_Q→PRIMARY, EARNINGS_RELEASE→SECONDARY. A comment explains why: audited regulatory filings are the source of record, while company-issued earnings releases are unaudited and corroborating.
- `parse_document_id` uses one compiled regex, `^(?P<company>[A-Z][A-Z0-9]{0,9})_(?P<doctype>10K|10Q|Q[1-4]_Earnings)_(?P<period>FY\d{2}|FY\d{4})$`. Map `10K`→TEN_K, `10Q`→TEN_Q and `Q1..Q4_Earnings`→EARNINGS_RELEASE. Normalize a 2-digit period by prefixing `20`, so FY23 becomes FY2023 and matches BenchmarkExample.period. Raise `ValueError` naming the offending id and the expected pattern on any mismatch. The regex deliberately rejects dots, slashes and lowercase letters.
- `Chunk` has an `@model_validator(mode="after")` that raises ValueError when `source_tier != SOURCE_TIER_BY_DOCUMENT_TYPE[document_type]`. This makes tagging consistent by construction.
- `RetrievedChunk(Chunk)` adds `score: float = Field(ge=-1.0, le=1.0, description="Cosine similarity; higher = more relevant")`.
- `RetrievalQuery` uses `model_config = {"frozen": True, "str_strip_whitespace": True}` with these fields: company min_length=1 max_length=32; period min_length=1 max_length=16; query min_length=1 max_length=2000; `document_type: DocumentType | None = None`; top_k default 5, ge=1, le=100.
- `RetrievalResult` has query, `chunks: tuple[RetrievedChunk, ...]`, backend and `latency_ms: float = Field(ge=0.0)`. Its `latency_seconds` property returns latency_ms / 1000; the docstring says this is the value for Appendix B `latency_breakdown["retrieval"]`.
- `RetrievalContractError(RuntimeError)`.
- `RetrievalBackend(ABC)`: `backend_name` property returns `type(self).__name__`. `retrieve()` is decorated `@typing.final`, takes keyword-only args and runs these steps in order:
  (a) Build a `RetrievalQuery`. A pydantic ValidationError propagates before any search or log.
  (b) `start = time.perf_counter()`; `chunks = self._search(request)`; `latency_ms = (time.perf_counter() - start) * 1000.0`.
  (c) Contract checks. Raise `RetrievalContractError` naming the backend when: len > top_k; any chunk's company/period differs from the request; document_type differs when a filter was set; or scores are not non-increasing.
  (d) Call `logger.info("retrieval call completed", component=LATENCY_COMPONENT, backend=..., company=..., period=..., document_type=(value or None), top_k=..., num_results=..., latency_ms=round(latency_ms, 3))`. Do not log query text or chunk text.
  (e) Return `RetrievalResult` with the unrounded latency_ms.
  `_search` is the single `@abstractmethod`. Its docstring says: return at most top_k chunks that match every filter, ranked by descending score; never log latency (the base class does).

3. src/jev_cot/retrieval/faiss_retriever.py — the FAISS backend.
- Define the three filename constants and `IndexManifest`: dimension/num_documents/num_chunks ge=1, `document_ids: tuple[str, ...]`.
- `SentenceTransformerEmbedder.__init__` does a lazy `from sentence_transformers import SentenceTransformer` inside the method (a comment explains: the heavy torch import is paid only when an embedder is built). It stores `self._model: Any = SentenceTransformer(model_name, device="cpu")` (CPU for determinism, NFR-01). Never pass `trust_remote_code`. Call `get_embedding_dimension()` and narrow the result with `isinstance(dim, int)`, raising ValueError when it is not an int.
- `encode()`: raise ValueError on an empty input. Call `model.encode(list(texts), batch_size=32, show_progress_bar=False, convert_to_numpy=True, normalize_embeddings=True)`. Convert with `np.ascontiguousarray(raw, dtype=np.float32)` (FAISS requires contiguous float32; the explicit conversion also satisfies mypy's warn_return_any). Raise ValueError when the result is not 2-D or its width is not `dimension`.
- `FaissRetriever.__init__` raises ValueError, with both values in the message, when: `index.ntotal != len(chunks)`; `manifest.num_chunks != len(chunks)`; `index.d != manifest.dimension`; `embedder.model_name != manifest.embedding_model`; or `embedder.dimension != manifest.dimension`. It stores chunks as a tuple.
- `from_index_dir` resolves the three artifact paths. For each missing one it raises `FileNotFoundError(f"FAISS index artifact not found: {path.resolve()} — build it with jev_cot.retrieval.ingest")`. It then loads the manifest via `IndexManifest.model_validate_json`, the chunks via `jsonlines` plus `Chunk.model_validate` per line in file order, and the index via `faiss.read_index(str(path))`. If `embedder` is None it builds `SentenceTransformerEmbedder(manifest.embedding_model)`, so ingest and query always share one model (research Pitfall 2).
- `_search`:
  - Compute the candidate positions whose company and period match, and whose document_type matches when the filter is set. Return [] if there are none.
  - Encode the query and call `index.search(query_vec, index.ntotal)`. This ranks the whole index exactly; production-scale indexing is a ROADMAP non-goal.
  - Skip ids below 0 and non-candidates.
  - Score each hit as `max(-1.0, min(1.0, 1.0 - float(d) / 2.0))`.
  - Build `RetrievedChunk.model_validate({**chunk.model_dump(), "score": score})`.
  - Sort by `(-score, chunk_id)` for deterministic ties and return the first top_k.

4. src/jev_cot/retrieval/ingest.py — the ingest pipeline (the CLI `main()` is added by plan 04-05, not here).
- `read_document` reads UTF-8 and drops every line whose `lstrip()` starts with `#`.
- `chunk_text`:
  - Raise ValueError unless `0 <= overlap_words < max_words`.
  - Split paragraphs on the regex `\n\s*\n`, collapse internal whitespace with `" ".join(p.split())` and skip empty paragraphs.
  - A paragraph of at most max_words words becomes one chunk.
  - A longer paragraph becomes windows with step `max_words - overlap_words`, stopping once a window reaches the paragraph end. Never emit a window fully contained in the previous one.
- `discover_documents` raises FileNotFoundError (resolved path) when the directory is missing. Otherwise it returns `sorted(p for p in dir.glob("*.txt") if p.is_file())`, non-recursive, and raises ValueError when that list is empty (never index an empty corpus — research Pitfall 1).

Chunk the output of read_document and raise ValueError if a document yields zero chunks. Build each `Chunk` with `chunk_id=f"{document_id}::{i:03d}"` and all metadata copied from `DocumentMetadata`. The source tier is tagged here, once, at ingest.
- `build_index`:

  - Call load_chunks BEFORE creating index_dir, so failures leave no partial artifacts.

The manifest has no timestamp, so rebuilds are byte-stable.
  - Log `logger.info("ingest completed", component="ingest", num_documents=..., num_chunks=..., latency_ms=...)` and return the manifest.
